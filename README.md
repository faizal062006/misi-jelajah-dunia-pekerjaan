## 🎯 Capaian & Tujuan Pembelajaran
1. Siswa mampu mengenali **8 jenis profesi hebat** dalam kehidupan masyarakat.
2. Siswa mampu menjelaskan tugas, tanggung jawab, dan peran setiap pekerjaan.
3. Siswa mampu mengidentifikasi alat-alat khas yang digunakan oleh setiap profesi.
4. Siswa mengenal lingkungan dan tempat kerja masing-masing profesi.
5. Siswa memahami bahwa seluruh profesi memiliki manfaat mulia bagi masyarakat.
6. Siswa mengasah kompetensi dasar pada **5 Mata Pelajaran Pokok Kelas 4 SD**:
   - 📐 **Matematika**: Pengukuran luas panen, keliling, koordinat arah & sudut navigasi.
   - 🇮🇩 **PKn**: Norma hukum dan ketertiban jalan raya, musyawarah mufakat, hak & kewajiban warga negara.
   - 📖 **Bahasa Indonesia**: Kosakata baku istilah pekerjaan, membaca pemahaman teks cerita profesi.
   - 🎨 **SBdP**: Estetika seni tata hidang masakan, kerajinan jaring dan ornamen bahari.
   - 🏃 **PJOK**: Ketahanan fisik penanggulangan kebakaran, gizi seimbang, dan pertolongan pertama (P3K).

## 🎮 Fitur Utama Game (Sisi Siswa)

### 1. Login Nama yang Disediakan Guru
* Siswa cukup memilih namanya dari daftar kelas (misal: *Aisyah Zahra, Budi Santoso, Citra Kirana*, dll.) tanpa perlu mengetik manual.
* Nilai, riwayat pos, dan bintang yang telah diperoleh akan otomatis tersinkronisasi.

### 2. Peta Petualangan 3D Pulau Profesi & 8 Pos Berlatar Khusus
Setiap pos pekerjaan memiliki pemandangan visual tematik yang sesuai:
* 👨‍🏫 **Pos Guru**: Papan tulis kapur sekolah hijau tua, rumus Matematika, dan meja kayu kelas.
* 🩺 **Pos Dokter**: Ruang periksa klinis toska-sian dengan grafik detak jantung ECG dan palang medis.
* 👮 **Pos Polisi**: Langit malam biru tua kepolisian, lampu patroli darurat, dan marka jalan raya.
* 🌾 **Pos Petani**: Hamparan persawahan terasering hijau keemasan fajar dan bulir padi.
* ✈️ **Pos Pilot**: Langit biru stratosfer dan landasan pacu (*runway*) perspektif berlampu landasan.
* 🎣 **Pos Nelayan**: Ombak samudera biru, kapal layar tradisional, dan dermaga kayu.
* 👨‍🍳 **Pos Koki**: Dapur restoran bistro hangat, wajan tembaga gantung, dan kepulan uap masakan.
* 🚒 **Pos Pemadam Kebakaran**: Markas merah berani damkar, pintu armada, dan hidran air.

### 3. Mini Game Interaktif
* **Mini Game 1**: Tebak Profesi berdasarkan gambar dan petunjuk.
* **Mini Game 2**: Pasangkan Alat dan Profesi (*drag and drop*).
* **Mini Game 3**: Siapa Aku? (*tebak teka-teki profesi*).
* **Mini Game 4**: Pilih Tempat Kerja yang sesuai.
* **Tantangan Akhir**: Kuis 10 soal acak dengan pembahasan dan skor otomatis.

### 4. Sistem Anti-Kecurangan (*Anti-Cheat Detection*)
* Mendeteksi otomatis apabila siswa berpindah tab browser atau meminimalkan jendela kuis.
* Menampilkan modal peringatan layar penuh dengan alarm suara agar siswa tetap jujur.
* Merekam setiap insiden beserta stempel waktu ke Dashboard Guru.

### 5. Sertifikat Digital & Medali Kelulusan
* Diberikan otomatis setelah menyelesaikan petualangan.
* Menampilkan nama siswa, predikat medali (Emas, Perak, Perunggu), skor akhir, dan tanggal selesai.
* Siap cetak langsung (*Print to PDF*).

## 💻 Panduan Menjalankan di Komputer Lokal

### Prasyarat
* [Node.js](https://nodejs.org/) versi 18 atau yang lebih baru
* npm atau yarn

### Langkah Instalasi
```bash
# 1. Clone repositori ini
git clone https://github.com/USERNAME/misi-jelajah-dunia-pekerjaan.git

# 2. Masuk ke direktori proyek
cd misi-jelajah-dunia-pekerjaan

# 3. Pasang seluruh dependensi
npm install

# 4. Jalankan server lokal
npm run dev
```
Buka browser di alamat: `http://localhost:3000`
